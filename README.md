## Código em linha e blocos de código

O comando `git status` mostra o estado atual do repositório

O comando `git add .` adiciona todos os arquivos modificados á *staging area(commits)*

O comando `git commit -m "Comentário"` registra as alterações com uma mensagem.

O comando `git push` envia os arquivos para a nuvem

```
Git status
Git add .
Git commit -m
Git push
```
